## 🏗️ Arquitectura del Sistema

Este proyecto es la cara visible de un sistema verificable compuesto por 5 módulos:

*   **MIS (Identidad Simbólica):** El sistema declara explícitamente ser una IA.
*   **MAS (Autoconocimiento):** Interpretaciones numerológicas reflexivas.
*   **MRA (Restricciones Éticas):** Filtro de seguridad y advertencias.
*   **MTI (Trazabilidad Inmutable):** Hashes SHA-256 y firmas digitales.
*   **MAR (Asignación de Responsabilidad):** Vinculación con un humano responsable mediante RFC/CURP.
